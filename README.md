# AYUSH Patient Case-Taking Software 🌿

A modern and responsive web-based **AYUSH Patient Case-Taking and Management System** designed to digitally manage patient information, clinical case records, examinations, AYUSH assessments, treatments, appointments, and follow-ups.

## 🚀 Features

- 🔐 Login and authentication interface
- 📊 Professional healthcare dashboard
- 👨‍⚕️ Patient registration and management
- 🔎 Patient search, filtering, and pagination
- 📋 Multi-step patient case-taking
- 🩺 Chief complaints and medical history
- 💊 Symptom and treatment management
- 🧑‍⚕️ AYUSH assessment
- 📏 Patient examination and BMI calculation
- 📅 Appointment management
- 🔄 Follow-up tracking
- 📈 Reports and analytics
- ⚙️ Settings and profile management
- 💾 LocalStorage-based data management
- 📱 Fully responsive design
- 🔔 Toast notifications and form validation

## 🛠️ Technologies Used

- HTML5
- CSS3
- Bootstrap 5
- Vanilla JavaScript
- Bootstrap Icons
- Chart.js
- LocalStorage

## 🎯 Purpose

The system is designed to provide a digital interface for **clinical documentation and case management** in AYUSH healthcare settings.

> **Disclaimer:** This software is intended for clinical documentation and case-management support. Medical assessment, diagnosis and treatment decisions remain the responsibility of the qualified practitioner.
